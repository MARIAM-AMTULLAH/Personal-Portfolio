MARIAM AMTULLAH — PORTFOLIO WEBSITE
==================================

FILES
-----
index.html       Home page
about.html       About, education, skills, training, interests
contact.html     Contact details and demo contact form
css/style.css    Shared styles and dark/light theme colors
js/script.js     Theme switch, mobile menu, contact-form mailto behavior
images/profile.svg  Placeholder profile illustration

HOW TO RUN
----------
1. Extract the Assignment-2 folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Test the navigation, theme switch, and mobile layout.

BEFORE SUBMITTING / PUBLISHING
------------------------------
1. In contact.html, replace your.email@example.com with your real professional email.
2. In js/script.js, replace the recipient value "your.email@example.com" with the same email.
3. Replace images/profile.svg with a professional photo if you prefer. If you use a JPG or PNG,
   update the image src in index.html accordingly.
4. Verify education dates, experience, training, and project descriptions.
5. Add real GitHub repository and live-demo links for each project.
6. Add your CV as assets/resume.pdf if you want a CV download link.
7. Remove any project or experience that you have not actually completed or cannot explain.
8. The contact form opens an email application; it does not send messages directly to a server.
9. This project uses a small amount of JavaScript for theme switching and mobile navigation.
   If your instructor requires HTML and CSS only, ask whether this is permitted or use a CSS-only
   theme toggle approach.

ASSIGNMENT CONCEPTS INCLUDED
----------------------------
HTML5 semantic elements: header, nav, main, section, article, footer
CSS selectors: element, class, ID, descendant, pseudo-classes
Box model: margin, padding, border, width
Flexbox: navbar, buttons, footer, contact links
Grid: hero, project cards, skills, contact layout
Forms: label, input, textarea, required, email input type
Images and links: profile illustration, navigation and social links
Hover effects: navigation, buttons, cards and links
Responsive design: flexible containers and CSS media queries
Interconnected pages: Home, About and Contact
